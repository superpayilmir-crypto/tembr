# Тембр

Музыкальный стриминг-плеер в стиле лофт. Треки независимых артистов из [Audius](https://audius.co) (MP3 320) и концерты без потерь (FLAC 16/24 бит) из [Internet Archive](https://archive.org/details/etree).

- `app/src/main/assets/index.html` — само приложение (работает и в браузере).
- Android-оболочка: WebView + фоновая служба с кнопками в уведомлении.
- APK собирается автоматически GitHub Actions и появляется в разделе **Releases**.
